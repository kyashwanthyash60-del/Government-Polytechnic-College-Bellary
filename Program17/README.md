# Program 17 – REST CRUD operations with MySQL using Spring Boot

This project follows the manual's Student entity, repository, service and REST controller structure. Dependencies: Spring Web, Spring Data JPA and MySQL Driver. Configure a local MySQL database in `application.properties`, run the Spring Boot application, then test GET/POST/PUT/DELETE using Postman.

Endpoints: `GET /student`, `POST /student`, `PUT /student`, `DELETE /student/{studentregno}`. Root endpoint returns a welcome message.

The manual's sample database credentials are not copied; set your own local credentials before running.

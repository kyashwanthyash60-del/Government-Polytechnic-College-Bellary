# Program 6 – Build a basic web application and deploy it to a cloud host

## Aim
Create a basic HTML form application and host it on a web hosting service.

## Application
Use the HTML form exercise (text input, select, file input and other form tags) as the sample web application. Keep the main HTML file as `index.html` if the hosting provider expects that default name.

## Deployment procedure in the manual
1. Create an account with a web hosting provider.
2. Open the hosting dashboard and its file manager.
3. Open the website's document root (often named `public_html`).
4. Upload the HTML file and any supporting assets.
5. Open the public website URL and verify the page loads.
6. Test the form and share the website URL.

**Current note:** The PDF names 000webhost as an example. Hosting providers and free-plan availability change over time; use a currently available host and follow its current deployment instructions.

# Program 7 – Registration form using JavaScript

**Manual task:** Create a registration or feedback form; after submit, hide the form and enable the display section using JavaScript.

**Files:** `Registration.html`, `Details.html`.

**Run:** Open `Registration.html` in a browser, enter the details, and submit. The manual's supplied code stores values in `localStorage` and opens `Details.html` to display them.

**Source note:** The PDF code is preserved. Although the task description mentions hiding/showing sections on the same page, the supplied example navigates to a separate details page.

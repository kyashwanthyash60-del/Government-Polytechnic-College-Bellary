# Program 2 – Create and manage a product backlog using Jira

## Aim
Create a Jira project backlog using user stories for a hall-booking application.

## User story: Customer registration
**As a** customer, **I want** registration functionality, **so that** I can register and use the service.

Scope: registration page, customer validation, ability to change phone number, browser compatibility and mobile compatibility. Precondition: customer has an email address and phone number.

Acceptance scenarios:
- Given I am on the registration page and enter a valid name and phone number, when I submit, then registration succeeds.
- Given I enter invalid customer details, when I submit, then an error message is shown.

## Other backlog stories
1. Check hall availability by location and date.
2. Book an available hall and allow date/location changes.
3. View and update booking details after a successful booking.

## Jira procedure
1. Sign in to Jira and create a project.
2. Choose a project template and name the project.
3. Create an issue of type **Story** for each requirement.
4. Enter a concise summary and put the user story and acceptance criteria in Description.
5. Prioritize stories in the backlog and refine them as requirements change.

The manual's wording and sample hall-booking requirements are retained; Jira menu labels may differ by version.

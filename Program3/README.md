# Program 3 – Create Sprint 1 with required user stories

## Aim
Create the first sprint in Jira and add the required user stories.

## Procedure
1. Sign in to Jira and open the project created for the practical.
2. Create Story issues and give each one a summary.
3. Add the user story and acceptance criteria in the Description field.
4. Open the Backlog and move the required stories into Sprint 1.
5. Start the sprint.
6. Open the Board and select Insights.
7. Open Sprint Burndown to review sprint progress.

## Evidence to submit
Capture the project, backlog with Sprint 1, started sprint and Sprint Burndown view. Jira's current interface may use slightly different labels.

# Program 20 – MongoDB CRUD through REST API using Spring Boot

Create a Spring Boot project with Spring Web, Spring Data MongoDB and (optionally) Lombok. This folder contains a runnable Book REST API based on the manual's example. Configure MongoDB and start the application.

Endpoints: `POST /addBook`, `GET /findAllBooks`, `DELETE /delete/{id}`. Example database name is `jss`; collection is `Book`. The manual also describes testing with Postman.

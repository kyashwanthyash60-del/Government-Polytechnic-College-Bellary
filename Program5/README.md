# Program 5 – Create a GitHub repository and perform push/pull operations

## Aim
Create a repository for Mini Project 1 and demonstrate GitHub operations.

## Create repository
1. Install Git for Windows from https://git-scm.com/downloads.
2. Sign in to GitHub in a browser.
3. Use the New repository option.
4. Enter a repository name such as `mini-project-1`, add a description and create it.

## Push/upload files
1. Open the repository and choose Add file → Upload files.
2. Select the project files.
3. Enter a commit message and choose Commit changes.

## Clone/pull
Use the Code menu to copy the repository URL, then clone it using Git or GitHub Desktop. Pull to retrieve the latest remote changes.

## Branching and merging
Create a branch, switch to it, make and commit changes, then merge the branch back into the target branch. In Git, the commands are `git branch newbranch`, `git checkout newbranch`, and `git merge newbranch` (run the merge while checked out to the branch receiving the changes).

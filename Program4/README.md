# Program 4 – Create UI/UX design for user stories (wireframing)

## Aim
Create a wireframe in Figma for the user stories.

## Procedure
1. Sign in to Figma using an account.
2. Create a new design file.
3. Add a frame and choose a suitable screen size from the right sidebar.
4. Set the frame background using the Fill section.
5. Use the Text tool (T) to add headings, labels and button text.
6. Add rectangles and other shapes as placeholders for images and interface elements.
7. Arrange the elements to represent the screens required by the stories (registration, hall availability, booking and booking details).
8. Save the design and capture screenshots for the practical record.

The manual refers to using components from the Figma Community as needed.
